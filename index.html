VaultMint

Privacy-first personal finance app for Indian users. Extracts transactions from bank SMS and PDF statements using an LLM pipeline that runs entirely on-device via Ollama — no statement data ever leaves the machine, and every field is AES-256-GCM encrypted with per-user keys underneath.

10+banks · SMS parsing
80+banks · IFSC lookup
100+UPI handles recognised
200+MCC merchant categories
Core ledger
AI-parsed SMS & PDF statements, reason-grouped review queue with bulk confirm/reject, merchant-alias learning, self-improving categorisation, free-form tags, per-category budgets with rollover and 80%/100% over-budget alerts.
Automatic capture
iOS Shortcut drops bank SMS straight into the on-device pipeline — no Apple API, nothing over the network. IMAP inbox polling extracts statement PDFs and unlocks password-protected ones from data already on file.
Insight & recurring
Deterministic recurring-transaction detection with next-charge prediction, cashflow trend and net-position tiles, credit-card fee-waiver progress, rewards summary, MoM category deltas.
India-specific
IFSC-based bank identification, UPI PSP recognition, ISO 18245 MCC mapping, India-only categories (Jewellery/Gold, Government, Religion/Charity), statement balance reconciliation to the rupee.
Stack — Java 21 · Spring Boot 4 · Spring AI · PostgreSQL · Redis 8 (cache + vector search) · Docling · SeaweedFS · Next.js 16 PWA

quorumdeck

A terminal console for running several AI agents — different models, different providers — side by side in one session. Most CLI clients give you one model and a dropdown to switch; quorumdeck starts from the opposite premise, that the useful thing is what happens when a Claude agent, a GPT agent, and a local Llama agent answer the same question at once, with tokens, latency, and cost shown next to each other so "which model for this" stops being a vibe.

5orchestration patterns
100+model backends via LiteLLM
Patterns
single · fanout · judge · debate · pipeline — same prompt run one, several, or staged ways, all working end to end.
Agents as config
A deck is a YAML file committed next to the code it's about — share a deck, not a screenshot. Credentials stay in the OS keychain, never in agents.yaml.
Cost control
Per-agent token/cost/wall-clock shown live; an optional hard budget_usd refuses the next turn once a deck's running total hits it.
Runs anywhere
Fully local decks against Ollama with no key and no network, or free multi-lab comparisons on OpenRouter's free tier with one key.
Stack — Python · LiteLLM

sgh-cli

GitHub's own gh is repository-scoped by design. sgh is the other axis: every command takes an organization and fans out across all of its repositories concurrently — cut a release branch in 200 repos, review every open PR your team filed this week, or find which repos still have branch protection disabled, in one command instead of a shell loop over the API.

Bulk git operations
Branches, tags, and pull requests — create, rename, delete, review, merge, close — across every repo at once, plus an interactive selector.
CI & compliance
List, view, rerun, cancel and dispatch Actions workflow runs with live monitoring; inspect and update branch-protection rules org-wide.
Built for scale
Concurrent worker pool, rate-limit tracking, exponential backoff, circuit breaking — and --dry-run on everything destructive, because a bulk operation across an org is one flag away from a bulk incident.
Scriptable
Table, compact, or JSON output; shell completion for Bash/Zsh/Fish/PowerShell; an interactive TUI dashboard when you'd rather browse.
